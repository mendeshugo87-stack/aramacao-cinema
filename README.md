# Aramacao Cinema

Base limpia para la plataforma de Aramacao Cinema.

La primera entrega es una maqueta estática de la página pública de Inicio, ubicada en `Frontend/`. No incluye Django, modelos, migraciones, base de datos ni dependencias instaladas.

Consulta `docs/` para el alcance de la portada, el contrato visual futuro con backend y los recursos pendientes.
