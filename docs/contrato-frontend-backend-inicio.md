# Contrato visual futuro: Inicio

Este documento describe únicamente los datos que el frontend necesita representar. No define modelos ni tablas.

## featured_movies

Lista ordenada para el carrusel. Cada elemento requiere título, descripción breve, género, clasificación, duración, idioma, URL de póster, URL opcional de banner, referencia de tráiler autorizada, estado y destino de horarios.

## current_movies

Lista de películas en cartelera. Cada elemento requiere título, género, clasificación, duración, idioma, póster, horarios visibles, estado de disponibilidad y destino de detalle o compra.

## upcoming_movies

Lista de próximos estrenos. Cada elemento requiere título, fecha de estreno, género, póster, resumen opcional y destino de detalle.

## screenings

Funciones visibles para la portada o vinculadas desde ella. Cada elemento debe permitir mostrar fecha, hora, película, idioma, formato, sala, disponibilidad y si admite promoción.

## active_promotions

Promociones activas que el frontend puede mostrar. Cada promoción requiere nombre, estado activo, días aplicables, mensaje comercial, condiciones, películas u horarios participantes y enlace de consulta.

## contact

Información oficial para encabezado, contacto y pie: dirección, teléfono, correo, URL de ubicación y enlaces a redes sociales.
